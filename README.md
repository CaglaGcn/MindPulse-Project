# MindPulse

MindPulse is a mental health risk analysis project focused on identifying employee groups with higher depression risk.

## Project Objective

The project analyzes demographic and workplace-related factors associated with depression and explores how multiple risk factors combine.

## Tools Used

- SQL
- Power BI
- Python / XGBoost
- Streamlit

## My Contribution

My main contributions to the project were:

- SQL-based data exploration and quality checks
- Missing value analysis
- Employee segmentation
- Depression rate analysis
- Compound risk analysis
- Power BI dashboard design
- Business insight generation
- Presentation and storytelling

The machine learning and Streamlit implementation were developed with assistance and used as a prototype layer.

## Key Findings

- Overall depression rate: 8.18%
- Younger employees showed substantially higher depression rates in this dataset
- Higher work pressure and lower job satisfaction were associated with higher depression rates
- The combination of high work pressure, low job satisfaction and less than 5 hours of sleep reached approximately 32.8% depression rate
- This high-risk segment contained 5,654 employees
